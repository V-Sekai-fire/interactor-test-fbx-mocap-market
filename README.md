# interactor-test-fbx-mocap-market

Motion-capture clips in FBX, each with reference OBJ frames and a record of its source and licence, for import tests.

## What it is for

An importer test reads each FBX clip and compares chosen frames with the OBJ exports beside it. A JSON record per clip gives its title, author, source, licence and the importer options it needs.

## Build and run

There is nothing to build; the files are read as they are.

## Licence

Each clip's licence is in its JSON record. The clips are CC BY-SA 4.0: the author named there must be credited, and anything derived from a clip carries the same licence. The repository adds none of its own.
